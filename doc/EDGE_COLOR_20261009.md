# SC520 外围红色残留修正（2026-10-09）

用户实拍反馈：上一版 `SC520_raw_color_bright_20261009.bit` 的中心绿已明显改善，白色误框已解决，但白板背景的外围仍偏红，左上最明显，其他边和角也有残留。本版保留上一版 RAW 九点表、整帧白平衡和显示提亮曲线，只增加显示支路的外围修正。

## 改动与边界

现有九点标定点位于内部（x=128/640/1152，y=90/360/630），点阵外采用边界增益延续。该处理不会自动补偿更靠外位置新增的色差。实拍表明仍需外围补偿，但无法仅凭手机照片准确恢复 SC520 原始 RGB；本版参数属于有幅度限制的残留调色，并非新的精密 RAW 标定。

新增 `user_source/hdl_source/video/display_edge_color.v`，接在 ROI 取数之后、既有显示提亮之前，六拍延迟，RGB/VS/HS/DE/保护信号一起延迟。独立恢复显示坐标，不影响 DDR 读取请求或识别坐标。

中心矩形 x=384..896、y=216..504 的新增增益精确为 1，中心显示与上一版保持一致。向四边平滑过渡，红通道按左右、上下交互权重修正，左上较强、左下较轻；蓝通道在左上略降低、右侧适度提高，绿色通道保持原值。扣除显示黑电平 14 后处理，14 以下原样输出。红残留增益范围 0.75..1，蓝为 0.9375..1.0625。OSD/框保护区域原色通过。

RAW/ISP/AWB、绿色和白色识别规则、ROI 框高度/稳定性、舵机、传感器配置、DDR、分辨率、时钟与引脚约束文件与上一版相同。识别输入也不变。本版仅修改顶层的显示支路连接，并给主工程添加新显示模块；新增同步延迟为六个 HDMI 像素时钟。

## 验证与实机确认

- 独立整数模型生成完整 720p 的 921600 个像素向量，检查全坐标、中心原样、黑电平、限幅、彩色/白色/绿色、空拍、旁路和 OSD 保护。
- 同时验证新增模块→原六拍增强旁路→原三拍共用提亮的完整十五拍 RGB/同步/保护信号对齐。
- 空间权重所有相邻像素的最大变化为 2/1024；中心区域新增增益精确为 1024/1024。
- 运行原七组 ModelSim 回归，继续检查亮白排除、绿色识别、ROI 高度/稳定性和处理预算。
- 最终综合、布局布线、时序、资源和校验值见 `SC520_edge_color_20261009_manifest.json`。

软件仿真证明算术和时序符合预期，不能代替实机光学确认。本版下载后使用同一白板背景比较左上、上下边和右侧色差即可，无需重复纯灰屏、遮盖镜头测试。如果外围仍有明显残留，下一步应采集本版各区域的直接 RGB 数值再定量调整，不能把手机照片当作传感器精确读数。

## 工程与下载

下载 `sim/build/SC520_edge_color_20261009.bit`。主工程 `td_project/camera_to_dsi_display.al` 已添加新模块，重新打开后可自行全流程编译。提供的 bit 在独立验证工程内重新综合、布局布线和生成，引用当前主工程生产 HDL/IP/引脚和时钟约束，验证 TCL 为 `td_project/rebuild_validation_edge_color_20261009.tcl`。

上一版 `sim/build/SC520_raw_color_bright_20261009.bit` 完整保留，可回退。修改前的顶层及主工程清单备份在 `sim/build/backup_edge_color_20261009/`。开发过程中评估过 RAW 外围候选，但它未用于最终工程；最终 RAW 源码与上一版一致，构建清单和 source_audit JSON 均可核对。
