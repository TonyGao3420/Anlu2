### 0.2 需要外部支持的两项

#### A. 帧缓存方案的决策（问题 2 的一部分）
**这是需要你"决策"，不是需要"信息"。**
一帧 1280×720 RGB888 需 **22.1Mbit**，片上 ERAM 仅 **108 片 ≈ 2.1Mbit**，差一个数量级，
必须三选一：

| 选项 | 说明 | 代价 |
|---|---|---|
| A1 引入 DDR2 帧缓存 | 与官方例程一致，可整帧 720p 实时显示 | 需引入官方 `ph1p35_ddr/ddr2` 全套（100+ 文件）+ DDR IP；DDR 校准失败会黑屏，排查成本高 |
| A2 不用 DDR，行缓存流式处理 | 纯 RTL、纯 BRAM，全程可仿真、时序风险低 | **无法整帧缓存** → 输出需降到 640×480，或做 2×2 降采样 |
| A3 先做 A2 打底，DDR 作为可插拔后端 | 先把"采集+输出"主线跑通并验证，DDR 后置 | 需先定义帧缓存接口抽象 |

> **建议 A3**：先用 A2 拿到可验证的贯通链路，再把 DDR 作为第二个实现接入。

## 问题 3　`tb_sc520_cfg.v` 的 I2C 从机模型未对齐 `uii2c` 的 SCL 相位

- **状态**：⚠️ **测试平台已重写、编译通过、从机能通信；但采样时机仍不对**
- **可否自行解决**：✅ 可自行解决（纯测试平台问题；`uicfgcs520` / `uii2c` 是官方代码）
- **文件**：`sim/tb/tb_sc520_cfg.v`

**已完成的工作**：

1. 阅读 `src/vendor/uii2c.v`，确认三件关键事实（已另记入 `doc/architecture.md`）：
   - 它是**纯计数器驱动**的状态机，**从机不响应也不会挂死**，
     只在 `W_ACK` 阶段检测到 `SDA=1` 时置 `O_iic_bus_error`；
   - 芯片 ID 读取是 **repeated start** 时序（`rd_req` 回 IDLE 再 START）；
   - 寄存器写入是**常规两字节写**（器件地址 + 1 个地址字节），
     进而说明 `W_ACK` 的 `O_iic_bus_error` 条件其实**永远满足**
     （两字节写下 `wcnt` 尚不满足重复起始条件）。
2. 据此把测试平台从"4 状态机"重写为**标准 I2C 事务模型**：
   第 1 字节判 R/W；写事务依次收地址高/低字节与数据；读事务回 0xEE / 0x4B。
   并区分**负向用例**（无从机 → 应报 `iic_error` 且不挂死）与
   **正向用例**（有从机 → ID 识别通过 + 寄存器写入）。

**当前现象**：

```
ERROR: 无从机时未在预期时间内置起 iic_error
ERROR: slave got wrong device addr 0x93      ← 正确应为 0x6C
sensor_id=0xZZZZ id_ok=0 cfg_done=0 iic_err=0 wr=0   TEST FAILED
```

从机**确实在通信**（收到了字节），但字节值错 → **采样时机不对**。

**根因（已定位）**：`uii2c` 的 **SCL 相位很特殊**：

```verilog
assign scl_offset = (clkdiv == OFFSET);                       // OFFSET = SCL_DIV - SCL_DIV/4
always @(posedge I_clk) O_iic_scl <= scl_offset ? scl_r : O_iic_scl;
```

即 `O_iic_scl` 相对内部 `scl_clk` 有 **3/4 个半周期的延迟偏移**，
而 SDA 是在 `scl_clk` 边沿变化的。用普通"检测 SCL 上升沿当拍采样"会采到跳变值。

**修复方向**（纯测试平台改动，不涉及 RTL）：
从机改为**在 SCL 高电平中点采样**，或对 SCL 做 4 倍过采样 + 数字滤波后在稳定区采样；
同时把"无从机时 iic_error 的预期时间"按 `CLK_DIV=36` 重算
（当前等待窗口可能偏小）。

**附带修正**：`ag` 固定为 176（最大模拟增益档）时，
`uics520regAE` 的 `step >= 160` 分支使 `I_AG[23:16] = 0x1F`，
`uii2c` 的 `W_ACK` 必然检测到 `SDA=1` → `O_iic_error` 常为 1。
这是 `uii2c` 的条件缺陷，**对实际配置流程无害**（写失败也继续），已在文档中记录。
