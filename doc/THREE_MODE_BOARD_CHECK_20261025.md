# 三模式上板观察步骤

本文件是后续实物核验步骤，不表示这些实物测试已完成。先打开 `td_project/camera_to_dsi_display.al`；直接下载本次主工程常规输出或命名产物均可，两者哈希应一致。

| 步骤 | 操作 | 应观察到 |
|---|---|---|
| 1 | SW1下、SW2下，摄像头对准绿色小球 | 原彩色画面、单目标ROI与屏幕中心坐标；原图标和文字正常 |
| 2 | 保持SW2下，SW1上，移动小球 | 原舵机控制继续跟随；再将SW1下拨，保持当前云台位置 |
| 3 | SW1下、SW2上，慢速移动小球 | ROI矩形保留原彩色；外围变为分块灰度和粗轮廓；小球后方出现连续橙色轨迹 |
| 4 | 移动到新位置后保持小球不动 | 旧路径逐段满约三秒后消退；当前位置持续被新检测刷新，当前点可一直保留 |
| 5 | 移走小球且画面内无其他绿色目标 | 原检测器短暂保持结束后不再生成新点，约三秒后旧轨迹清空 |
| 6 | SW2下，等一个完整画面后再上拨 | 原彩色画面恢复；重新进入风格化时不出现之前的轨迹 |
| 7 | SW2上时SW1上、下各试一次 | 风格化保持开启；SW1仍独立控制舵机是否继续追踪 |
| 8 | 在屏幕四边移动小球，观察框、文字和轨迹交叉 | 不应出现越界回卷或乱线；图标/文字/当前ROI应覆盖轨迹 |

SW2需约10ms稳定电平，之后在帧边界生效；短暂机械抖动不会改变模式。SW1沿用原同步和响应行为。三秒轨迹是屏幕坐标路径，量化约4像素、更新约一帧，不能当作世界坐标轨迹。云台将目标锁在中心时，屏幕轨迹集中在中心附近属于预期现象。

模式一、二的数字像素已逐像素核对，但所有模式统一增加约176µs显示延迟，不影响检测/舵机反馈计算。上板时还需观察真实摄像头、HDMI与舵机电气环境；仿真不能覆盖这些物理因素。
