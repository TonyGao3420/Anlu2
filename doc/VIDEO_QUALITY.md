# 视频色彩与红色目标检测

## 当前设置

当前 MIPI → ISP → DDR 帧缓存 → HDMI 链路及 ISP AWB 保持开启。目标检测读取 AWB/DDR 后、显示增强前的 RGB，不改写视频数据。HDMI输出末级只给未保护的相机画面每个RGB通道加6级，ROI框和OSD保持原色；动态ROI复位后先全屏捕获目标，命中后收缩到跟踪窗口，漏检时重新全屏搜索。

ISP AWB按每帧1/8误差量平滑，显示端仍旁路对比度、锐化、饱和度和Gamma；亮度偏移等量加到RGB三个通道，降低改变色相的风险。偏移只作用于相机画面，不改变红色检测输入。

红色检测门槛保持：红色色相容限为 `0.875 * chroma`，绝对色度下限8、相对色度下限为R/16、最低R值24；候选红色像素面积128至120,000，最小框宽高12像素，候选框内至少50%像素为红色。目标面积输出为20位。

## 能力边界

候选框内50%比例只代表红色像素在其自身外接框中的密度，不能证明整件物体超过一半面积为红色。当前也没有通用连通域分割；ROI内多个红色块可能合并。传感器寄存器中的自动白平衡若另行开启，也可能继续引入场景变化；本工程的软件 AWB 平滑不能控制传感器内部算法。

## 验证

按用户要求未运行仿真。2026-10-06 使用 TD 6.2.168116 对 PH1P35MDG324 完成综合和布局布线，最新结果在 `sim/build/td_validation_shared_awb/video_check_Runs/`：15,414/21,216 slices（72.65%）、39/108 ERAM、11/40 DSP；最终 WNS +0.106 ns、TNS 0，HWNS +0.020 ns、HTNS 0。相较之前的官方 AWB 基线18,920 slices（89.18%），减少3,506 slices（约18.5%）。层级报告中AWB由2,249 LUT / 2,452 ripple / 6,034 regs降至487 / 414 / 772；两路并行除法器改为共享迭代器。此项保留相同增益范围、Q16截取和每帧1/8平滑，未触碰显示像素通路。TD综合与布线通过不等同于上板画面已确认，建议上板复核颜色与首帧/帧间增益变化。
