# 选题二当前版上板核对

当前版尚未上板验证。以下是验收方法，不是已完成的实测结果。

1. 使用完整工程`td_project/camera_to_dsi_display.al`重新综合和布局布线，或下载`output/Anlu2_motion_style_20261026.bit`（干净ZIP内）。主工作区发布目录为`sim/build/track2_requirements_20261026/`。不要打开旧`prj/Anlu2.al`。
2. SW2下/SW1下：核对原彩色、绿色目标ROI、屏幕中心原点坐标、Logo/文字；亮白灯和白纸不应成为绿色目标。缓慢移动深绿、浅绿物体，确认框高度、单目标选择和坐标稳定性保持此前效果。右上角显示MODE:COLOR、MOT:-----。
3. SW2下/SW1上：核对原舵机追踪、机械行程和中心锁定；坐标、画面不能错位。切换SW1不应改变显示算法。
4. SW2上/SW1下：当前ROI矩形保留彩色，外部灰度块面/轮廓，平滑橙色轨迹约一秒消退；右上角MODE:STYLE。移动一个ROI外的物体，观察青色运动区域提示和MOT网格数变化；静止后应恢复。MOT是16×16格子数量，不是目标个数，提示/统计约晚一帧。
5. 第三模式突然整体改变光照或大范围转动相机：可能显示GLOBAL，并抑制大面积青色；这不保证ROI在所有光照下不丢失。记录目标重获时间和异常。云台转动会影响运动判断，未做相机运动补偿。
6. 第三模式SW1上，核对舵机追踪仍正常；轨迹为屏幕坐标，锁定后集中在中心属于预期，不是目标世界运动轨迹。反复进出第三模式，旧轨迹不应回来，不能出现半帧切换、文字被轨迹覆盖、Logo错色。
7. 建议连续运行两小时并反复移动目标、切换模式、突变光照，记录每次异常及时间。该时长是自测建议，非选题二明文门槛。需要同时用硬件调试/信号探针观察现有FIFO状态和帧计数/完整性，单看屏幕不能证明“从不溢出”。本版未新增FIFO溢出计数OSD，不能以MOT或原CNT替代。
8. 测量输入/输出VSYNC实际频率及重复/丢帧；当前输出理论约60.606Hz。测真实采集到显示延迟可用同一时基的帧标签/计时，或高帧率摄像同时拍事件与屏幕；原CNT只记录运行帧数，不等于延迟。

记录表建议列：日期、bit SHA256、显示器、光源、模式、开始/结束时间、输入/输出帧率、FIFO异常、目标丢失/重获、画面异常、照片/视频编号。实测完成后再将报告“待板验”改成通过或失败。
