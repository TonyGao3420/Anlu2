# 最新校色资源优化与组合模式

本轮基准为2026-10-30用户更新后的Anlu2，而不是28日旧bit：九点R增益为241/249/243、257/273/243、249/260/193；B增益为268/236/273、281/242/273、277/254/221。启用RGB_SHADING_ENABLE=1，POSITION_BIAS_ENABLE=0。用户最新visual_servo_pwm.v方向、死区、限位和步长参数均按原文件保留。

先单独完成资源优化。原九点双线性插值的四路水平乘法改为三张1024×18位原生ERAM表，分别存三行R/B水平插值结果；系数、舍入、截断、黑电平、饱和、保护标志以及8拍流水接口保持原样。垂直差分限定为已证明足够的有符号9位，减少无用符号扩展。正常TD GUI编译不需要Python，必须保留video/shading_row0.mif～shading_row2.mif。

2764800有效像素的随机RGB、全坐标梯度、黑白绿、保护、复位和画外边界对照通过。完整四模式对照使用修改前最新顶层和校色代码，检查所有像素、ROI、PWM与DDR读请求。只有优化版时序、资源和完整对照都通过后，才执行组合模式接入；优化版中间结果保存在sim/build/resource_combo_20261030/optimization_passed。

组合模式复用原检测器、八目标结果、背景风格化、同一个ROI元数据位和原视频缓存，不新增整帧RGB缓存。SW2独立选择风格化，SW3独立选择多目标：两者同时开时，对所有有效八目标ROI矩形的并集保留完整原RGB，框外维持原灰色简化与轮廓。目标高光、白色、暗面和其他颜色不再按像素绿色掩码丢弃。多目标框与计数照常叠加，HUD显示MODE:MULTI+STYLE。

组合标志在风格化输入帧首锁存；八组坐标直接复用检测器已经在SOF锁存、有效帧内保持不变的结果，省去重复坐标寄存器和大量帧首选择器。仿真逐像素断言该接口契约；独立模块仍提供本地快照选项，两种实现的完整像素/同步输出已比较一致。ROI并集随已有像素/同步元数据一起经过缓存，避免帧内切换或框闪动。SW2关、SW3开仍是原彩色多目标；SW2开、SW3关仍是原单目标风格化；都关时由SW1保留单目标/舵机追踪。SW1仍控制原主目标云台；一秒轨迹仍是原主目标轨迹，不新增八份轨迹缓存或八路舵机控制。

显示叠加模块也直接复用检测器的帧稳定坐标，省去另一组重复坐标寄存器；通用模块默认仍保持原本的本地快照行为。3686400个全分辨率像素专门对照验证了八框、四角、无效槽、保护区域、文字及三拍同步/RGB完全一致；主工程还逐像素断言检测器坐标在有效帧期间保持稳定。

最终还对ISP白平衡的除法实现作了等价优化。它每帧只启动一次计算，原实现却用了两个可连续输入的50拍流水除法器。现在用48次迭代和原50拍完成接口计算完整48位无符号商，不减少精度；帧尺寸过小、不能保证启动间隔的通用配置自动沿用原IP。136组官方IP/数学三方对照验证商和done逐拍一致；16帧15720个四通道像素对照验证RGB、握手、增益、候选值和更新时刻完全一致，包括短消隐、不合格样本、中断帧和复位。原累加、筛选、黑电平、限幅、平滑、SOF生效与50拍像素缓存均未改变。原IP网表和其余ISP源码保留原样。

原相机配置、RAW、ISP图像算法、180度转正、阈值、连通域、目标关联、云台代码、Logo、字体、亮度、轨迹算法、引脚和时钟约束保持最新基准原样。组合模式有意改变SW2/SW3同时开启时的显示行为，其余模式须与基准逐像素一致。

校色ROM可由tools/resource_combo_20261030/generate_shading_rom.py从display_color_shading.v中保留的九点系数函数重新生成；当前文件已生成，复制工程和GUI编译无需先运行脚本。如果今后手动修改九点系数，必须同步重新生成三张MIF，不可只修改函数而沿用旧数据。
